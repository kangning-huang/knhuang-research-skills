# ABT叙事结构评估工具（中文版）

使用「而且-但是-因此」框架评估科学写作。重点评估项目申请书和论文的摘要与引言部分，面向环境科学/城市科学领域。

## ABT框架核心

科学叙事遵循：**而且**（背景铺垫）→ **但是**（张力制造）→ **因此**（问题解决）

- **而且（AND）**：建立已知背景。引用相关文献，构建问题框架。
- **但是（BUT）**：识别关键缺口。制造必须解决的张力。
- **因此（THEREFORE）**：提出解决方案。展示方法/结果如何填补缺口。

## 评估流程

### 1. 判断文档类型
- **项目申请书**：前瞻性文档；「因此」聚焦于拟采用的方法和预期贡献
- **学术论文**：回顾性文档；「因此」包含已获得的结果和已证实的影响

根据文档类型，参阅 [references/proposal-criteria-zh.md](references/proposal-criteria-zh.md) 或 [references/paper-criteria-zh.md](references/paper-criteria-zh.md) 获取针对性评估标准。

### 2. 提取ABT成分

解析引言/摘要，识别：
- **而且部分**：背景陈述、引用文献、已建立的知识
- **因此部分**：拟议方法、方法合理性论证、预期/已证实的成果
- **但是部分**：缺口声明、张力所在、「然而/但是/却」等转折标志

### 3. 逐成分评估

#### 「而且」评估
1. **引文覆盖度**：提取所有引用文献。使用Hugging Face论文搜索和网络搜索验证：
   - 引文存在且来源可信（同行评审期刊、知名机构）
   - 引用内容准确反映原文（无曲解）
   - 覆盖面恰当——既不过于稀疏（遗漏关键文献）也不过于冗杂（缺乏聚焦）
2. **框架质量**：引文是否为研究问题构建了连贯的基础？

#### 「但是」评估
1. **缺口清晰度**：是否存在清晰、具体的知识缺口？
2. **缺口重要性**：该缺口为何重要？对以下方面的影响：
   - 科学领域进步
   - 技术发展
   - 政策干预
   - 社会问题解决
3. **逻辑衔接**：缺口是否自然地从「而且」部分引出？

#### 「因此」评估
1. **方法-缺口匹配**：问题与方法之间是否「手套合手」般契合？
2. **可行性/创新性**：方法是否恰当且具有足够创新？
3. **仅针对论文**：结果是否真正解决了所述缺口？有何更广泛启示？

### 4. 引文核查（完整检索）

对「而且」部分的每条引文：
```
1. 搜索：使用Hugging Face:paper_search和web_search定位论文
2. 获取：使用web_fetch获取摘要/全文（如可获得）
3. 核实：检查引用声明是否与原文实际发现一致
4. 评估：来源是否可信？是否经同行评审？时效性如何？
```

标记问题：
- 引文无法找到或获取
- 引用内容曲解原文
- 来源非同行评审或可信度低
- 遗漏近期关键文献

### 5. 判断问题严重程度

将每个问题分类为：
- **致命缺陷**：可能导致拒稿/不予资助；必须解决（如：缺少缺口声明、方法无法解决所述问题、引文曲解原文）
- **显著不足**：降低竞争力但非致命（如：缺口重要性不清、引文不完整）
- **轻微问题**：润色层面的改进（如：措辞、行文流畅度）

### 6. 生成评估报告

输出结构：

```
## ABT叙事结构评估报告

### 总体判断
[一句话：叙事结构 强/尚可/弱]

### 而且（背景与文献）
[框架和引文的评估]
- 问题严重程度：[致命/显著/轻微/无]

### 但是（知识缺口）
[缺口识别和重要性的评估]
- 问题严重程度：[致命/显著/轻微/无]

### 因此（问题解决）
[方法-缺口匹配及启示的评估]
- 问题严重程度：[致命/显著/轻微/无]

### 引文核查
[引文检查摘要；标记任何问题]

### 主要修改建议
**核心问题**：[1-2句话指出最重要的改进方向]

**具体建议**：
1. [简明、可操作的建议]
2. [简明、可操作的建议]
3. [简明、可操作的建议]
```

## 领域校准：环境科学/城市科学

评估引文覆盖度时，参考以下领域规范：
- 城市气候论文通常引用20-40篇参考文献；引言部分涉及8-15篇核心文献
- 必要文献包括奠基性著作（Oke、Stewart & Oke的LCZ体系）及近期进展
- 跨学科框架受到重视——与公共健康、能源、规划的关联可强化「而且」部分
- 方法部分应引用验证研究和数据来源

本领域常见致命缺陷：
- 忽视尺度不匹配（如：从点位测量声称城市级别结论）
- 将模拟研究作为观测证据引用
- 遗漏快速发展子领域的近期高影响论文（如热暴露、城市标度律）

## 中文科研写作特殊考量

### NSFC申请书特点
- 篇幅限制严格，需在有限空间内完成ABT结构
- 通常要求「立项依据」「研究内容」「研究目标」等固定板块
- 评审人期望看到对国内外研究现状的系统梳理
- 需要明确说明「拟解决的关键科学问题」

### 常见中文写作问题
- ABT结构不清晰，三个部分混杂
- 「但是」部分过于笼统（「研究较少」「尚不清楚」）
- 「因此」部分与「但是」部分脱节
- 过度引用申请人自己的工作，缺乏领域全景
- 文献综述变成流水账，未能构建叙事张力

## 重要原则

- **仅提供评估**：不重写文档。提供评价和建议。
- **建设性语气**：以帮助改进为目标，而非否定。
- **肯定优点**：在指出改进空间的同时，指出做得好的地方。
- **承认不确定性**：如无法核实某引文，说明此情况，而非假定有误。

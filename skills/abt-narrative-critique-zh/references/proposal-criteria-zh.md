# 项目申请书评估标准

项目申请书是前瞻性文档。ABT结构必须说服评审人该研究值得资助。

## 而且：文献综述质量

**检查要点：**
- 框架是否建立了领域现状，同时避免面面俱到？
- 是否同时引用了奠基性文献和最新进展？
- 范围是否与资助类型匹配？（NSFC面上/青年/重点项目有不同期望）
- 文献是否指向缺口，还是像断开的清单？

**引文密度参考：**
- NSFC面上项目：通常15-25条参考文献；立项依据部分5-10条核心引文
- NSFC青年项目：10-20条参考文献；聚焦度要求更高
- NSFC重点项目：25-40条参考文献；需要更全面的领域覆盖
- 省部级基金：通常10-15条聚焦引文

**致命缺陷：**
- 缺少任何评审人都会期望看到的奠基性文献
- 过度引用申请人自己的工作，缺乏更广泛的背景
- 文献综述与拟开展研究脱节

**显著不足：**
- 快速发展领域中引文过旧（AI/ML、城市热岛领域无2020年后文献）
- 覆盖不平衡（方法文献强，应用领域文献弱）
- 国内外研究现状梳理失衡

## 但是：面向资助竞争力的缺口声明

**检查要点：**
- 缺口是否足够具体，能在拟定周期内解决？
- 缺口是否足够重要，值得申请的资助额度？
- 缺口声明是否避免了平凡真理（「尚无人在Y城市研究X」）？
- 重要性是否用评审人关心的语言表述？

**重要性框架：**
对于环境/城市科学申请，缺口应关联到：
1. 科学推进（新理论、新机制、新认识）
2. 方法创新（新技术、数据融合、验证方法）
3. 社会影响（气候适应、公共健康、环境公平）
4. 政策相关性（对城市规划者、政策制定者可行动）

**NSFC特有要求：**
- 明确陈述「拟解决的关键科学问题」
- 科学问题需与研究内容紧密对应
- 避免把「科学问题」写成「研究内容」的简单重复

**致命缺陷：**
- 无明确缺口声明（从背景直接跳到方法）
- 缺口是平凡的（「以前没人做过这个」）
- 缺口与文献综述脱节
- 「关键科学问题」缺失或表述模糊

**显著不足：**
- 缺口重要性仅陈述未论证
- 多个缺口稀释焦点
- 缺口对于项目周期/经费过于宏大

## 因此：拟开展研究的匹配度

**检查要点：**
- 拟采用的方法是否直接针对所述缺口？
- 是否有清晰的逻辑链：缺口 → 方法 → 预期成果？
- 研究基础是否足以证明可行性？
- 时间安排是否与研究范围匹配？

**方法-缺口匹配测试：**
- 能否完成这个句子：「因为[缺口]，我们将[方法]，这将揭示[成果]」？
- 拟采用的方法是否同样适合回答另一个问题？（如果是，匹配度弱）
- 方法是否足够新颖值得资助，还是常规应用？

**预期成果：**
申请书应阐明：
- 具体交付物（数据集、模型、论文）
- 结果如何推进领域发展
- 更广泛影响（人才培养、科普、政策参与）

**NSFC特有要求：**
- 研究内容、研究目标、拟解决的关键科学问题需要高度一致
- 技术路线图需清晰展示方法如何解决问题
- 预期成果需量化且合理（论文数量、专利等）

**致命缺陷：**
- 方法无法解决所述缺口
- 高风险方法缺乏前期基础
- 成果模糊（「将有助于理解」）
- 研究内容与科学问题错位

**显著不足：**
- 方法是增量式而非创新式
- 时间安排不现实
- 「更广泛影响」像事后添加
- 研究基础与拟开展工作关联不紧密
